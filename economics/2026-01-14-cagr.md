# CAGR (연평균 성장률, Compound Annual Growth Rate)

**작성일**: 2026년 1월 14일

---

## 1. CAGR 정의

CAGR(Compound Annual Growth Rate, 연평균 성장률)는 일정 기간 동안 투자 또는 사업이 매년 일정한 비율로 성장했다고 가정했을 때의 **연평균 성장률**을 나타내는 지표입니다. 복리 효과를 반영하여 여러 해에 걸친 성장을 단일 연율로 표준화합니다.

### 계산 공식

```
CAGR = [(최종값 / 초기값)^(1/기간) - 1] × 100%
```

또는

```
CAGR = [(EV / BV)^(1/n) - 1] × 100%

여기서:
- EV (Ending Value) = 최종값
- BV (Beginning Value) = 초기값
- n = 기간(연수)
```

### 예시

**기업 매출 성장**
- 초기 매출 (2020년): $100M (약 1,400억원)
- 최종 매출 (2025년): $200M (약 2,800억원)
- 기간: 5년
- **CAGR = [(200 / 100)^(1/5) - 1] × 100% = [2^0.2 - 1] × 100% = 14.87%**

이는 매년 평균적으로 약 14.87%씩 복리 성장했음을 의미합니다.

## 2. CAGR vs 단순 평균 성장률

### 2.1 왜 CAGR이 필요한가?

단순 평균 성장률은 복리 효과를 무시하므로, 실제 성장 패턴을 왜곡할 수 있습니다.

### 2.2 비교 예시

**시나리오: 5년간 매출 추이**

| 연도 | 매출 | YoY 성장률 |
|------|------|-----------|
| 2020 | $100M | - |
| 2021 | $120M | +20% |
| 2022 | $110M | -8.3% |
| 2023 | $140M | +27.3% |
| 2024 | $150M | +7.1% |
| 2025 | $180M | +20% |

**단순 평균 성장률**
```
평균 = (20% - 8.3% + 27.3% + 7.1% + 20%) / 5 = 13.22%
```

**CAGR**
```
CAGR = [(180 / 100)^(1/5) - 1] × 100%
     = [1.8^0.2 - 1] × 100%
     = 12.47%
```

**차이점**
- 단순 평균: 13.22% (변동성 무시)
- CAGR: 12.47% (복리 효과 반영, 더 정확)
- CAGR이 더 낮은 이유: 2022년 마이너스 성장의 영향이 복리로 누적

### 2.3 극단적인 사례

**변동성이 큰 경우**

| 연도 | 포트폴리오 가치 | 연간 수익률 |
|------|----------------|-----------|
| 2020 | $100,000 (약 1.4억원) | - |
| 2021 | $150,000 (약 2.1억원) | +50% |
| 2022 | $100,000 (약 1.4억원) | -33.3% |

- 단순 평균 수익률: (50% - 33.3%) / 2 = **+8.35%**
- 실제 CAGR: [(100,000 / 100,000)^(1/2) - 1] = **0%** (원금 동일)

**결론**: 변동성이 클수록 단순 평균은 실제 성장을 과대평가합니다.

## 3. CAGR의 활용 분야

### 3.1 기업 재무 분석

**매출 성장률**
```
매출 CAGR = [(2025년 매출 / 2020년 매출)^(1/5) - 1] × 100%
```

**활용 예시**
- Tesla 매출 CAGR (2015-2020): **51%** (초고속 성장)
- Apple 매출 CAGR (2015-2020): **8%** (성숙 단계)
- 일반 S&P 500 기업 평균: **5-7%**

**이익 성장률**
```
EPS CAGR = [(2025년 EPS / 2020년 EPS)^(1/5) - 1] × 100%
```

**사례: NVIDIA (2019-2024년)**
- 2019년 EPS: $4.52
- 2024년 EPS: $25.00 (예상)
- EPS CAGR: [(25.00 / 4.52)^(1/5) - 1] × 100% = **40.8%**
- 해석: AI 반도체 호황으로 이익이 연평균 40% 이상 급성장

### 3.2 시장 규모 및 산업 분석

**TAM (Total Addressable Market) 성장률**

**예시: 글로벌 전기차 시장**
- 2020년 시장 규모: $162B (약 227조원)
- 2030년 예상 규모: $800B (약 1,120조원)
- 기간: 10년
- **CAGR = [(800 / 162)^(1/10) - 1] × 100% = 17.4%**
- 해석: 전기차 시장은 연평균 17% 이상 성장 예상

**업종별 평균 CAGR (2020-2030년 전망)**
| 산업 | CAGR | 특징 |
|------|------|------|
| AI/클라우드 | 25-35% | 초고성장 |
| 전기차 | 17-20% | 고성장 |
| 이커머스 | 10-15% | 성장 |
| 소비재 | 3-5% | 저성장 |
| 담배 | -2~0% | 쇠퇴 |

### 3.3 주식 투자 수익률

**주가 CAGR**
```
주가 CAGR = [(현재 주가 / 과거 주가)^(1/기간) - 1] × 100%
```

**예시: 10년 투자 수익률 (2015-2025년)**

| 종목 | 2015년 주가 | 2025년 주가 | CAGR |
|------|------------|------------|------|
| NVIDIA | $6 (약 8,400원) | $500 (약 700,000원) | 52.8% |
| Apple | $25 (약 35,000원) | $180 (약 252,000원) | 21.9% |
| Microsoft | $45 (약 63,000원) | $420 (약 588,000원) | 25.2% |
| S&P 500 | $2,000 | $5,800 | 11.2% |

**해석**
- NVIDIA: 연평균 52.8% 수익 (10년에 83배 상승)
- S&P 500: 연평균 11.2% (역사적 평균 약 10%)

### 3.4 배당 성장률

**배당 CAGR**
```
배당 CAGR = [(현재 DPS / 과거 DPS)^(1/기간) - 1] × 100%
```

**예시: Johnson & Johnson (2015-2025년)**
- 2015년 DPS: $2.95 (약 4,130원)
- 2025년 DPS: $4.76 (약 6,664원)
- 배당 CAGR: [(4.76 / 2.95)^(1/10) - 1] × 100% = **4.9%**
- 해석: 60년 연속 배당 인상, 안정적인 연 5% 성장

### 3.5 인플레이션 조정

**실질 성장률 계산**
```
실질 CAGR = 명목 CAGR - 평균 인플레이션율
```

**예시**
- 명목 매출 CAGR: 10%
- 기간 중 평균 인플레이션: 3%
- **실질 CAGR = 10% - 3% = 7%**
- 해석: 물가 상승을 제외한 실질 성장은 7%

## 4. CAGR 계산 실전 예시

### 4.1 포트폴리오 수익률

**시나리오: 5년 투자**

| 연도 | 포트폴리오 가치 | 연간 수익률 |
|------|----------------|-----------|
| 2020 | $50,000 (약 7,000만원) | - |
| 2021 | $60,000 (약 8,400만원) | +20% |
| 2022 | $54,000 (약 7,560만원) | -10% |
| 2023 | $64,800 (약 9,072만원) | +20% |
| 2024 | $71,280 (약 9,979만원) | +10% |
| 2025 | $85,536 (약 1.2억원) | +20% |

**계산**
```
CAGR = [(85,536 / 50,000)^(1/5) - 1] × 100%
     = [1.7107^0.2 - 1] × 100%
     = 11.35%
```

**해석**
- 단순 평균 수익률: (20% - 10% + 20% + 10% + 20%) / 5 = 12%
- 실제 CAGR: 11.35% (복리 효과 반영)
- 5년간 총 수익률: 71.1%

### 4.2 기업 가치 평가

**DCF 모델의 성장률 가정**

**예시: SaaS 스타트업 밸류에이션**
- 현재 ARR (Annual Recurring Revenue): $10M (약 140억원)
- 5년 후 목표 ARR: $100M (약 1,400억원)
- 필요 CAGR: [(100 / 10)^(1/5) - 1] × 100% = **58.5%**

**투자 판단**
- VC가 요구하는 성장률: 60%+
- 현실적 달성 가능성 평가 필수

### 4.3 국가별 GDP 성장률

**예시: 한국 vs 베트남 (2015-2025년)**

**한국**
- 2015년 GDP: $1.46T (약 2,044조원)
- 2025년 GDP: $1.80T (약 2,520조원)
- CAGR: 2.1% (성숙 경제)

**베트남**
- 2015년 GDP: $193B (약 270조원)
- 2025년 GDP: $430B (약 602조원)
- CAGR: 8.3% (신흥국 고성장)

## 5. CAGR 해석 가이드

### 5.1 성장률 수준별 의미

**초고성장 (30%+)**
- 특징: 하이퍼그로스 기업/시장
- 예시: AI 반도체, SaaS 유니콘
- 지속 가능성: 5년 이내 (이후 둔화 일반적)
- 투자 의미: 고위험 고수익, 높은 PER 정당화

**고성장 (15-30%)**
- 특징: 성장주
- 예시: 빅테크, 신흥시장
- 지속 가능성: 10년 가능
- 투자 의미: 장기 투자 매력적, PER 25-40배

**중성장 (7-15%)**
- 특징: 양질의 성장
- 예시: 소비재 우량주, 산업재
- 지속 가능성: 장기 지속 가능
- 투자 의미: 안정적 성장, PER 18-25배

**저성장 (0-7%)**
- 특징: 성숙 산업
- 예시: 유틸리티, 통신
- 지속 가능성: 무한정
- 투자 의미: 배당 중심, PER 12-18배

**마이너스 성장 (<0%)**
- 특징: 쇠퇴 산업
- 예시: 전통 미디어, 화석연료
- 투자 의미: 가치 함정 주의

### 5.2 복리의 마법 (Rule of 72)

**72의 법칙**
```
원금이 2배가 되는 기간(년) ≈ 72 / CAGR(%)
```

**예시**

| CAGR | 2배 도달 기간 | 10배 도달 기간 |
|------|-------------|--------------|
| 5% | 14.4년 | 47년 |
| 10% | 7.2년 | 24년 |
| 15% | 4.8년 | 16년 |
| 20% | 3.6년 | 12년 |
| 30% | 2.4년 | 8년 |

**실전 적용**
- S&P 500 (CAGR 10%): 7년마다 자산 2배
- Warren Buffett (CAGR 20%): 3.6년마다 자산 2배
- NVIDIA (2015-2025, CAGR 52%): 1.4년마다 자산 2배

## 6. CAGR의 한계점

### 6.1 변동성 무시

**문제점**
- CAGR은 시작점과 끝점만 고려
- 중간 과정의 변동성 완전 무시
- 같은 CAGR이라도 리스크는 천차만별

**예시: 두 투자안 비교**

**투자 A (안정형)**
| 연도 | 수익률 | 누적 가치 |
|------|--------|----------|
| 1 | +10% | $110,000 |
| 2 | +10% | $121,000 |
| 3 | +10% | $133,100 |
| **CAGR** | **10%** | |

**투자 B (변동형)**
| 연도 | 수익률 | 누적 가치 |
|------|--------|----------|
| 1 | +50% | $150,000 |
| 2 | -30% | $105,000 |
| 3 | +26.8% | $133,100 |
| **CAGR** | **10%** | |

- 두 투자 모두 CAGR 10% 동일
- 하지만 투자 B의 변동성(리스크)이 훨씬 높음
- **보완책**: CAGR + 표준편차(변동성) 함께 분석

### 6.2 과거 성과가 미래를 보장하지 않음

**문제점**
- 과거 CAGR로 미래를 외삽하는 오류
- 성장률은 시간이 지날수록 둔화 경향 (대수의 법칙)

**예시: Amazon**
- 1997-2007 매출 CAGR: **92%** (스타트업 단계)
- 2007-2017 매출 CAGR: **26%** (고성장)
- 2017-2027 예상 CAGR: **12%** (성숙 단계)

**투자 시사점**
- 과거 CAGR을 미래에 그대로 적용 금지
- 산업 성숙도, 경쟁 환경 변화 고려 필수

### 6.3 시작점/종료점 의존성

**문제점**
- 시작 시점과 종료 시점을 어떻게 설정하느냐에 따라 CAGR 크게 변동
- 특히 경기 순환주는 왜곡 심함

**예시: 항공사 매출 (COVID-19 영향)**

**시나리오 1: 2015-2019 (COVID 전)**
- CAGR: +8%

**시나리오 2: 2015-2020 (COVID 포함)**
- CAGR: -10%

**시나리오 3: 2015-2025 (회복 포함)**
- CAGR: +3%

**대책**
- 경기 정점 → 정점, 저점 → 저점으로 측정
- 또는 충분히 긴 기간(10년+) 사용

### 6.4 일회성 이벤트 반영 불가

**CAGR이 왜곡되는 경우**
1. **M&A**: 대형 인수 후 매출 급증
2. **자산 매각**: 일회성 이익
3. **회계 변경**: 기준 변경으로 매출 증가
4. **주식 분할/병합**: 주가 기준 CAGR 왜곡

**예시: 회사가 3년차에 경쟁사 인수**
- 인수 전 매출 CAGR: 10%
- 인수 후 전체 CAGR: 35% (일회성 증가 반영)
- **오해**: 회사가 매년 35% 성장한다고 착각
- **실제**: 유기적(Organic) 성장은 여전히 10%

**대책**
- Organic CAGR 별도 계산 (M&A 제외)

## 7. CAGR 활용 시 주의사항

### 7.1 적절한 기간 선택

**기간별 적합성**

**단기 (1-3년)**
- ❌ CAGR 의미 약함 (변동성 영향 큼)
- ✅ 단순 총 수익률 사용 권장

**중기 (3-7년)**
- ✅ CAGR 유용
- 경기 사이클 1회 포함
- 실적 추세 파악 적합

**장기 (10년+)**
- ✅ CAGR 가장 유용
- 변동성 평활화
- 구조적 성장 추세 파악

### 7.2 보완 지표 병행

**1. 표준편차 (변동성)**
```
연간 수익률 표준편차 = √[Σ(각 연도 수익률 - 평균 수익률)² / 연수]
```

**2. 샤프 비율 (위험 대비 수익)**
```
샤프 비율 = (CAGR - 무위험 이자율) / 표준편차
```

**3. 최대 낙폭 (MDD: Maximum Drawdown)**
```
MDD = (고점 대비 최대 하락폭 / 고점) × 100%
```

**예시: 두 포트폴리오 비교**

| 지표 | 포트폴리오 A | 포트폴리오 B |
|------|-------------|-------------|
| CAGR | 10% | 10% |
| 표준편차 | 8% | 18% |
| 샤프 비율 | 0.88 | 0.39 |
| MDD | -15% | -40% |
| **평가** | **우수** | 불안정 |

**결론**: 같은 CAGR이라도 A가 훨씬 우수한 투자

### 7.3 산업 및 기업 단계별 벤치마크

**스타트업 (설립 0-5년)**
- 매출 CAGR 목표: 50-200%
- 주의: 적자 일반적, EBITDA 성장률도 함께 확인

**성장기 기업 (설립 5-15년)**
- 매출 CAGR 목표: 20-50%
- 이익 CAGR > 매출 CAGR (마진 개선 필수)

**성숙 대기업**
- 매출 CAGR 목표: 5-15%
- FCF CAGR이 더 중요

**업종별 CAGR 벤치마크 (S&P 500)**
| 업종 | 매출 CAGR (10년) | EPS CAGR (10년) |
|------|-----------------|----------------|
| Technology | 12-18% | 15-25% |
| Healthcare | 8-12% | 10-15% |
| Consumer | 5-10% | 8-12% |
| Financials | 3-8% | 8-15% (경기 순환) |
| Energy | -2~5% | 변동 심함 |

## 8. CAGR 실전 투자 전략

### 8.1 성장 스크리닝

**기준 설정 예시**

**공격적 성장주**
- 매출 CAGR (5년) > 20%
- EPS CAGR (5년) > 25%
- PEG Ratio < 2
- Forward CAGR 유지 또는 가속

**안정 성장주 (GARP)**
- 매출 CAGR (10년) > 10%
- EPS CAGR (10년) > 12%
- PEG Ratio < 1.5
- 배당 CAGR > 5%

### 8.2 목표 수익률 설정

**현실적 CAGR 목표**

**보수적 투자자**
- S&P 500 인덱스: 9-11% CAGR 기대
- 배당 재투자 시: 10-12% CAGR

**적극적 투자자**
- 개별 성장주: 15-20% CAGR 목표
- 변동성 감내 필요

**공격적 투자자**
- 집중 투자 + 레버리지: 25%+ CAGR 목표
- 높은 리스크

### 8.3 장기 투자 시뮬레이션

**예시: 은퇴 자금 계획**

**목표**
- 현재 자산: $100,000 (약 1.4억원)
- 목표 자산 (20년 후): $1,000,000 (약 14억원)
- 필요 CAGR: [(1,000,000 / 100,000)^(1/20) - 1] × 100% = **12.2%**

**투자 전략**
- 12.2% CAGR 달성 위해 성장주 60% + 채권 40% 포트폴리오
- 또는 S&P 500 + 소액 추가 납입

**연간 추가 납입 시**
- 초기 투자: $100,000
- 연간 추가: $10,000 (약 1,400만원)
- 필요 CAGR: 8.7% (부담 완화)

## 9. CAGR 계산 도구

### 9.1 엑셀/구글 시트 공식

**기본 공식**
```excel
=POWER(최종값/초기값, 1/기간) - 1
```

**예시**
```excel
=POWER(B10/B1, 1/9) - 1
// B1: 초기값, B10: 최종값, 기간: 9년
```

**백분율 표시**
```excel
=(POWER(최종값/초기값, 1/기간) - 1) * 100
```

### 9.2 연도가 정확히 떨어지지 않을 때

**일자 기준 CAGR**
```excel
=POWER(최종값/초기값, 365/DAYS(시작일, 종료일)) - 1
```

**예시**
- 시작: 2020년 3월 15일 → $50,000
- 종료: 2025년 9월 20일 → $95,000
- 정확한 기간: 5.52년
- CAGR = [(95,000 / 50,000)^(1/5.52) - 1] × 100% = 11.2%

## 11. 투자 체크리스트

CAGR 기반 투자 분석 시 다음 사항을 확인하세요:

### 11.1 CAGR 계산 검증
- [ ] **적절한 기간 선택** (최소 3년, 이상적으로 5-10년)
- [ ] **시작/종료 시점 타당성** (경기 사이클 고려)
- [ ] **일회성 이벤트 제외** (M&A, 자산 매각 등)
- [ ] **Organic vs Inorganic 성장 구분**

### 11.2 성장의 질 분석
- [ ] **매출 vs 이익 CAGR 비교** (이익 성장 > 매출 성장?)
- [ ] **마진 추이** (유지 또는 개선?)
- [ ] **FCF CAGR 확인** (현금 창출 능력)
- [ ] **자사주 매입 의존도** (>50%면 경고)

### 11.3 지속 가능성 평가
- [ ] **Forward CAGR 전망** (과거와 유사한 성장 가능?)
- [ ] **시장 성장률 vs 기업 성장률** (시장보다 빠른 성장?)
- [ ] **경쟁 환경 변화** (진입 장벽, 규제)
- [ ] **대수의 법칙** (매출 규모가 커지면 성장률 둔화 필연)

### 11.4 밸류에이션
- [ ] **PEG Ratio** (PER / EPS CAGR < 1.5?)
- [ ] **Price/Sales vs 매출 CAGR**
- [ ] **현재 성장률이 주가에 이미 반영되었는가?**

### 11.5 리스크 확인
- [ ] **변동성** (표준편차, MDD)
- [ ] **CAGR 달성 실패 시 시나리오**
- [ ] **업황 역풍 시 방어력**

## 12. 결론

CAGR은 **장기 성장 추세를 단일 숫자로 표준화**하는 강력한 도구입니다.

### 핵심 원칙

- ✅ **복리 효과 반영** - 단순 평균보다 정확
- ✅ **장기 투자 필수 지표** - 3년 이상 데이터 사용
- ✅ **비교 가능성** - 기업/산업/시장 간 성장률 비교 용이
- ✅ **미래 예측 참고** - 하지만 과거≠미래 명심
- ❌ **변동성 무시** - 표준편차, MDD 등 보완 필요
- ❌ **맹신 금지** - 시작/종료점 의존, 일회성 이벤트 왜곡 가능

### 투자자 행동 지침

1. **스크리닝**: 매출/EPS CAGR로 성장주 후보 추출
2. **벤치마킹**: 업종 평균 CAGR과 비교
3. **밸류에이션**: PEG Ratio로 성장 대비 가격 평가
4. **리스크 관리**: CAGR + 변동성 + MDD 종합 판단
5. **장기 관점**: 최소 5-10년 CAGR 추세 확인

**가장 중요한 것**: CAGR은 **과거 성과**를 요약하는 도구일 뿐, **미래 성장을 보장하지 않습니다**. 기업의 경쟁력, 산업 전망, 거시 환경을 종합적으로 분석해야 합니다.
